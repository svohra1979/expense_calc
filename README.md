# Expense Tracker

A small vanilla JavaScript app for tracking expenses. No build step or dependencies.

## Features

- Add expenses with a description, amount, category and date
- Filter by category and by month
- Summary cards for total, count and top category, matching the filtered list
- Delete with confirmation
- Data is saved in the browser with `localStorage`

## Run it

Open `index.html` in a browser.

## Files

- `index.html` – page structure
- `style.css` – styling
- `script.js` – state, filtering, rendering and storage
